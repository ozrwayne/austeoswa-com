# austeoswa.com 新闻稿写作规范 · 去 AI 味

## 定位

本 skill 只做一件事：**识别并清除 AI 味**。

它**不**规定"必须多短一句"、"必须单句成段"、"必须以时间开头"这类**体裁节奏**——那些是社交媒体推文的规则。新闻稿保留正式感（完整句子、段落层次、机构名不省略、"近日"这类书面时间锚都允许）。

**判定**：删掉某句/某段后，事实是否变模糊？不变 → 删；变了 → 保留但优化措辞。

**权威源**：`/Users/xu_g/Desktop/AI-Admin-System/记忆库/语义记忆/` 下 Roland 手动校准的两份指纹。本 skill 只抽取**通用 AI 味清单**，不搬体裁规则。

### 软词 / 主观弱表达
```
或许 / 也许 / 大概 / 估计 / 我觉得 / 我认为 / 在我看来
```
新闻要陈述事实，不要输出主观揣测。

### 标点
- 破折号 `——` `—`：滥用禁（一篇 ≤ 1 处）
- 省略号 `……` `...`：禁
- 冒号 `：` 引出**列项**（"策略 3 个：A / B / C"）：禁
- 冒号做**自然引语前缀**（他说："…"）或**简短同位语**（"目的很简单：保护投资者"）：允许

## 结构禁忌

### 冒号引出列项 → 改成自然语流

| ⚫ AI | ✅ 人 |
|---|---|
| "赞助方 3 家：比亚迪 / ABC 纸业 / …" | "本次赞助方包括比亚迪、澳洲 ABC 纸业等昆士兰本地企业。" |

### 工整对仗（一篇 ≤ 1 处）

字数、句式、词性高度对称的对偶都算：
- ❌ "CEO 32 亿身家 / CTO 17 亿身家"
- ❌ "拼硬件、堆规模 / 拼服务、建生态"
- ❌ "敢答、能答、答得对"（三连排比升华）
- ✅ 具体三联式（三项都是具体名词 / 动作）："美国、加拿大、澳大利亚、新西兰"

### 结尾两连击 严禁

- 倒数第二句：升华金句（"X 是 A，Y 才是 B" / "这就是 X，这才是 Y"）
- 倒数第一句：教育祈使（"以后要 X" / "你应该 Y" / "请永远 X"）

### 未来式空承诺 严禁

- ❌ "未来将持续深化合作，让 X 的声音被更广泛地听见"
- ❌ "青年会将继续搭建平台，助力 X 把握先机"
- 事实性的展望（"下一站将于 X 月 X 日在 Y 举行"）允许

### 元叙述 严禁

- ❌ "这背后是…"
- ❌ "这意味着…"
- ❌ "值得一提的是…"
- ❌ "更重要的是…"
- 直接讲事实，让事实自己承载重要性。

---

## 具体性要求

全文应含 ≥ 3 件**具体性元素**（数字 / 专名 / 具体场景）。这是 AI 味最本质的对立面——AI 倾向抽象，人倾向具体。

- ❌ "多家企业赞助" → ✅ "比亚迪腾势、澳洲 ABC 纸业等"
- ❌ "上百位嘉宾出席" → ✅ "约 160 位嘉宾与观众"
- ❌ "在布里斯班某影院举办" → ✅ "在布里斯班格拉瓦特山影院举办"

## 词汇替换速查

| ⚫ AI 触发词 | ✅ 换成 |
|---|---|
| 机制 / 系统 / 框架 | 删整句，换具体动作或场景 |
| 至关重要 / 关键性的 | 删形容词，用具体后果 |
| 我觉得 / 或许 / 大概 | 删软词，直接陈述事实 |
| 不是 X 是 Y | 拆两句直说 |
| 这就是 X / 这才是 X | 删收尾金句 |
| 首先 / 其次 / 值得注意的是 | 删，直接进内容 |
| X 的本质 / X 的底层逻辑 | 删整句，直接说事 |
| 银弹幻觉 / 证伪 | 大白话 |
| 让 X 被更广泛地听见 | 删整段结尾 |
| 意思是 / 举个例子 | 直接说，不要教学口气 |

## 工作流程

1. **起草**：先按事实写完，别管腔调
2. **grep 黑名单**：全文搜上面所有词表 — 命中 = 该句重写
3. **跑结构禁忌**：冒号列项 / 对仗 / 两连击 / 未来式承诺 / 元叙述 各扫一遍
4. **查具体性**：全文有 ≥ 3 件具体性元素？没有就补
5. **默读**：从头念一遍，卡壳的句子重写
6. **任一项未过 = 重写该句/该段**（不是改字面）

## 与推文体裁的区别

以下推文场景规则**不适用**本 skill：
- 极短句 ≤ 10 字必备
- 单句成段
- 句长波动强制
- 时间锚定开头率 ≥ 40%
- 直接断 / 反问开放式收尾
- 口语助词高频（其实 / 反而 / 就去做吧）

新闻稿保留通稿正式感即可。
