# austeoswa.com 新闻稿写作规范

## ⚠️ 使用前先读：新闻 ≠ 推文

本 skill 的规则源自 Roland 的**推文人类味指纹**（社交媒体场景），但**新闻稿是不同体裁**。2026-07-22 用户拒绝了一版把规则完全照搬的 WIS 稿子——"根本就不像新闻"。

**新闻稿要保留的正式感**：
- 完整、成句、有段落层次
- 事实密度高、少口语助词
- 允许一定的"通稿感"：主办方全称、机构名不省略、时间地点书面化
- **别写成"会长发朋友圈"**

**新闻稿要去掉的 AI 味**（skill 主要作用于此）：
- 抽象名词堆砌（信息治理 / 语义层重写 / 底层逻辑）
- 强解释元叙述（这背后是… / 这意味着… / 值得一提的是）
- 未来式空承诺（未来将持续深化 / 让 X 被更广泛地听见）
- 对仗升华金句（敢答、能答、答得对）
- 破折号插入语滥用

**判定**：删掉这句、这段之后，读者对"这件事发生了什么"的理解**不受影响** → 那就删。
反之，删了之后新闻要点变模糊 → 保留，只优化措辞。

## 词级黑名单（grep 命中 = 该句重写）

### 抽象名词（AI 最容易堆的空词）
```
机制 / 系统 / 生态 / 维度 / 范式 / 框架 / 闭环 / 链路
底层 / 表层 / 路径依赖 / 协同 / 归因 / 属性 / 迁移
颗粒度 / 心智模型 / 银弹 / 证伪 / 锚点 / 张力
信息治理 / 语义层重写 / 富文档 / 上限解锁器
```

### 学术化高级形容词
```
稳健的 / 强大的 / 全面的 / 微妙的 / 关键的 / 深远的
显著的 / 有意义的 / 有价值的 / 引人注目的
充满活力 / 持久的 / 关键性的 / 不断演变 / 格局
至关重要 / 深远的影响 / 全方位
```

### AI 句首
```
首先 / 其次 / 最后 / 综上 / 总而言之 / 与此同时
事实上 / 值得注意的是 / 毫无疑问 / 不可否认
众所周知 / 不言而喻 / 此外
```

### AI 抽象模板
```
X 的本质是 Y      X 的底层逻辑是 Y     X 的核心机制是 Y
这就是 X          这才是 X            你以为 X 实际上 Y
不是 X 是 Y       不是 X 而是 Y       真正的问题在于
重新评估 X 这件事  X 被定位成 Y        X 的时代过去了
```

### 软词 / 不确定词
```
或许 / 也许 / 大概 / 估计 / 通常 / 往往
一般来说 / 我觉得 / 我认为 / 在我看来
```

### AI 教学连接词
```
意思是 / 举个例子 / 解法是 / 做法是 / 关键是
问题在于 / 原因在于 / 本质是
```
口语连接词（"其实就是"、"说白了"、"翻译一下"）**保留**。

### 标点
- 破折号 `——` `—`：**全禁**
- 省略号 `……` `...`：**全禁**
- 冒号 `：` 引出列项（"X：YYY"、"策略 3 个：A / B / C"）：**禁**
- 冒号做**自然引语前缀**（他说："…"）或**简短同位语**（"目的很简单：保护投资者"）：允许

## 结构禁忌

### 冒号引出列项
`拿到了什么：… / 举个例子：… / 解法：…` → 改成自然语流。

| ⚫ AI | ✅ 人 |
|---|---|
| "赞助方 3 家：比亚迪 / ABC 纸业 / …" | "比亚迪来了。ABC 纸业也是本地赞助。另外还有…" |

### 工整对仗（每篇 ≤ 1 处）
- ❌ "CEO 32 亿身家 / CTO 17 亿身家"
- ❌ "拼硬件、堆规模 / 拼服务、建生态"
- ❌ "敢答、能答、答得对"
- ✅ 具体三联式（"农业时代靠土地，工业时代靠机器，信息时代靠知识"）— 三项都是**具体名词/动作**

### 结尾两连击 严禁
- 倒数第二句：升华金句（"X 是 A，Y 才是 B" / "这就是 X，这才是 Y"）
- 倒数第一句：教育祈使（"以后要 X" / "你应该 Y" / "记住 Z" / "请永远 X"）

### 未来式空承诺 严禁
- ❌ "未来将持续深化合作，让 X 的声音被更广泛地听见"
- ❌ "青年会将继续搭建平台，助力 X 把握先机"
- ✅ 就事写事，不给愿景收尾

---

## 收尾优先级（从高到低）

1. **直接断**（不总结）
2. **反问开放**（不给答案）
3. **单句吐槽 / 点名问题**
4. **自然描述 / 纯叙事收尾**

**心法**：让事实自己说话。读者扫完最后两句想骂/想转/想笑，而不是被你"教育"了一下。

---

## 必做项（每篇都要满足）

- [ ] 至少 1 处**时间锚定**（"6 月 24 日" / "近日" / 年份）
- [ ] 全文含 ≥ 3 件**具体性元素**（数字 / 专名 / 具体场景）
- [ ] 抽象名词密度**逼近 0**
- [ ] 无破折号插入语滥用（一篇 ≤ 1 处）
- [ ] 无未来式空承诺
- [ ] 无解释性元叙述（这意味着 / 这背后是 / 值得一提的是）

⚠️ **推文规则不搬到新闻**：极短句 ≤ 10 字、句长波动、单句成段、避免通稿式陈述——这些**在新闻稿里不强制**。新闻可以正式、可以段落完整。

## 词汇替换速查

| ⚫ AI 触发词 | ✅ 换成 |
|---|---|
| 机制 / 系统 / 框架 | 删整句，换具体动作或场景 |
| 至关重要 / 关键性的 | 删形容词，用具体后果（"不做这步，后面全废"）|
| 我觉得 / 或许 / 大概 | 删软词，直接下判断 |
| 不是 X 是 Y / 不是 X 而是 Y | 拆两句直说 |
| 这就是 X / 这才是 X | 删收尾金句，换观察或反问 |
| 首先 / 其次 / 值得注意的是 | 删，直接进内容 |
| X 的本质 / X 的底层逻辑 | 删整句，直接说事 |
| 银弹幻觉 / 证伪 | 大白话："这套打法不灵了" |
| 充满活力 / 格局 | 删整句，换具体场景 |
| 让 X 被更广泛地听见 | 删整段结尾，改成事实断句 |

## 前 → 后 改写案例

**#1 空词堆砌 → 具体动作**
- ❌ "WIS 为青年会提供的这套 AI 搜索增强方案，核心不是堆关键词，而是让每一场活动的事实以 AI 可读、可核验的方式沉淀在公网中"
- ✅ "WIS 做的事很实。把活动时间、地点、主办方、到场嘉宾这些事实一条条挂进官网，让 AI 有据可查"

**#2 未来式承诺 → 事实断句**
- ❌ "未来，青年会将继续与 WIS 保持深度协作，把每一场活动、每一位成员的故事，都以 AI 可读、事实可核的方式沉淀下来，让在澳潮汕青年的声音，被更广泛地听见"
- ✅ "感谢 WIS。链接在 https://www.wayneinsightspring.com/"

**#3 对仗金句 → 具体细节**
- ❌ "AI 才能敢答、能答、答得对"
- ✅ "AI 才敢开口。开口之后，答得也对"（还是三连不好，可改成："AI 就能直接说：主办方是青年会 + CMC。不再拼凑"）

**#4 AI 句首 → 直接进事**
- ❌ "值得一提的是，本次首映礼的赞助商均是昆士兰州本地的企业"
- ✅ "赞助商全部来自昆士兰本地"

## 工作流程

写稿或改稿时，按顺序：

1. **起草**：先按事实把内容写完，别管腔调
2. **grep 黑名单**：全文搜上面所有词表 — 命中一条 = 该句重写
3. **跑 §必做项**：checklist 走一遍
4. **跑 §结构禁忌**：冒号列项 / 对仗 / 两连击 / 未来式承诺 各扫一遍
5. **默读**：从头念一遍，卡壳的句子重写
6. **任一项未过 = 整段重写**（不是改字面）
